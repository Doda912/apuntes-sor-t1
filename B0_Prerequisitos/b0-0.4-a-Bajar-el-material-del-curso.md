## ⌨️ Comandos y pasos importantes

- `pwd` - Muestra la ruta de la carpeta actual.
    
- `ls -l` - Muestra los archivos y carpetas del directorio.
    
- `cd nombre_carpeta` - Permite entrar en una carpeta.
    
- `cd ..` - Permite volver a la carpeta anterior.
    
- `git clone dirección_SSH` - Descarga un repositorio de GitHub.
    
- `git status` - Comprueba el estado del repositorio.
    
- `git remote -v` - Muestra la dirección del repositorio remoto.
    
- `git add .` - Añade los archivos para prepararlos para guardar.
    
- `git commit -m "mensaje"` - Guarda los cambios con un mensaje.
    
- `git push` - Sube los cambios a GitHub.

## 🤔 Respuestas a las preguntas

- **¿Qué diferencia hay entre descargar mediante ZIP y clonar con Git?**  
    Con ZIP solamente descargamos los archivos, mientras que con `git clone` también descargamos el historial y la información del repositorio.
    
- **¿Para qué sirve Use this template?**  
    Sirve para crear una copia propia de un repositorio, manteniendo sus archivos pero teniendo nuestro propio historial.
    
- **¿Para qué sirve git clone?**  
    Para descargar un repositorio de GitHub a nuestro ordenador.
    
- **¿Por qué utilizamos SSH?**  
    Para identificarnos y poder trabajar con nuestros repositorios de GitHub de forma segura.
