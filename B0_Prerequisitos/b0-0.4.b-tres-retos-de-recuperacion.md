## **🎯 Qué se pedía**

Realizar tres retos de recuperación de archivos utilizando Git y GitHub. El objetivo era aprender a recuperar archivos borrados y entender qué ocurre cuando eliminamos una carpeta completa o archivos que todavía no hemos subido a GitHub.

## **⌨️ Comandos y pasos importantes**

- `git status` — comprobar el estado de los archivos.
    
- `git restore` — recuperar archivos eliminados que todavía están registrados en Git.
    
- `git clone` — volver a descargar un repositorio desde GitHub.
    
- `git log --oneline` — consultar el historial de cambios.
    
- `pwd` — comprobar en qué directorio estamos.
    
- `cd ..` — subir al directorio anterior.

## **🤔 Respuestas a las preguntas**

1. **¿Se necesita Internet para recuperar los archivos del primer reto?** No, porque el historial de Git sigue guardado en el ordenador.
    
2. **¿Por qué no funciona Git restore en el segundo reto?** Porque al borrar la carpeta completa también se elimina la carpeta oculta `.git`.
    
3. **¿Por qué no se recuperan las anotaciones del tercer reto?** Porque no había hecho commit ni push y, por tanto, no estaban guardadas en GitHub.
