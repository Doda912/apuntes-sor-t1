## ⌨️ Comandos y pasos importantes

- `pwd` — Comprueba la ruta en la que estamos trabajando.
    
- `git init` — Inicializa un repositorio Git en la carpeta actual.
    
- `git branch -M main` — Establece el nombre de la rama principal como `main`.
    
- `git status` — Muestra el estado de los archivos del repositorio.
    
- `git remote add origin URL` — Conecta el repositorio local con GitHub.
    
- `git add nombre_archivo` — Prepara un archivo para guardarlo en Git.
    
- `git add .` — Prepara todos los cambios de la carpeta.
    
- `git commit -m "mensaje"` — Guarda los cambios con un mensaje descriptivo.
    
- `git push -u origin main` — Sube los cambios a GitHub y establece la conexión con la rama remota.
    
- `git push` — Sube los siguientes cambios a GitHub.
    
- `git log --oneline` — Muestra el historial de commits de forma resumida.
    
- `q` — Permite salir del paginador cuando aparece la información de comandos como `git log`.
